# Roadmap

## Version 1

- Portable YAML protocol and JSON Schemas
- Blank workspace templates and fictional fixtures
- Progressive master-resume interview skill
- Read-only Career Kit import skill

## Candidates for later versions

- `audit-career-facts`
- `tailor-resume`
- `write-cover-letter`
- Optional cross-platform validator or CLI
- Document exporters and workspace migrations

These are directions, not compatibility promises.
